Each version includes a true vector SVG (closed Bezier paths; no embedded raster image) and a 2048 x 2048 transparent RGBA PNG.
The triangle and comma are transparent cutouts, not white shapes. All PNG backgrounds are transparent. The circle version uses an outline ring, not a solid background.
SVG is the file to use for unlimited scaling. PNG is a high-resolution raster export.
logo-preview.png uses a checkerboard ONLY to show transparency; the checkerboard is not included in the individual logo assets.

Colors follow the website mood board. Main artwork is preserved from the approved rounded monochrome reference and smoothed during vector tracing.
